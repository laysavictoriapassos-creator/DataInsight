# 📊 DataInsight

### Plataforma inteligente de análise de dados

O DataInsight é uma aplicação desenvolvida em Python que permite importar planilhas e transformar dados em informações visuais e organizadas.

## 🚀 Funcionalidades

- Importação de arquivos CSV e Excel.
- Visualização de dados em tabelas.
- Indicadores automáticos.
- Identificação de valores vazios.
- Gráficos interativos.
- Estatísticas descritivas.
- Download de relatórios em CSV.

## 🛠️ Tecnologias utilizadas

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL

## 💻 Como executar o projeto

1. Clone este repositório.
2. Instale as dependências:

bash
pip install -r requirements.txt


3. Execute a aplicação:

bash
streamlit run app.py


## 🎯 Objetivo

Facilitar a análise de dados por meio de uma interface simples, intuitiva e interativa.
